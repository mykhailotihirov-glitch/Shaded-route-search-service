# Shade Route

## Опис проєкту

Shade Route MVP — це концепція мобільного застосунку для пішоходів, який допомагає будувати міські маршрути з урахуванням рівня затіненості вулиць. Мета застосунку — зробити пересування містом комфортнішим у спекотну погоду.

## Основні можливості

- Побудова маршрутів для пішоходів.
- Врахування рівня затіненості міських вулиць.
- Відображення маршрутів на карті.
- Надання користувачу можливості обрати комфортніший маршрут.

## Технології

Для розробки інтерфейсу планується використання Flutter і Dart, для роботи з картографічними даними — OpenStreetMap, а для контролю версій та командної взаємодії — Git і GitHub.
